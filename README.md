\# 高校宿舍报修智能工单管理系统



\## 项目简介

本系统是基于Flask开发的宿舍报修工单管理平台，用于解决高校传统宿舍报修流程混乱、维修进度不可查询、维修过程缺少记录等痛点。

系统划分学生、宿舍管理员、维修人员三类角色，实现报修提交、工单审核派单、维修处理、服务评价的完整闭环业务流程。



\## 技术架构

\- 前端：HTML + CSS + JavaScript

\- 后端：Python Flask

\- 数据库：SQLite



\## 项目文件说明

\- docs：存放《宿舍智能报修工单管理系统需求说明书》、业务流程图、数据库ER图等设计文档



\## 功能模块

1\. 学生报修模块：登录、提交报修工单、查看个人工单进度、维修完成后进行评价

2\. 管理员工单管理模块：查看全部工单、审核工单、工单驳回、派单给维修人员、历史工单检索

3\. 维修人员模块：接收分配工单、查看故障详情、填写维修记录、完结工单

4\. 服务评价模块：学生对维修服务进行星级+文字评价，工单归档



\## 工单流转

待提交 → 待管理员接单 → 已派单（维修中） → 维修完成 → 评价结束
