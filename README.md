高校宿舍报修智能工单管理系统
 
项目简介
 
本系统是基于 Flask 开发的轻量化高校宿舍报修工单管理系统，针对校园宿舍设备故障报修场景开发。
系统区分学生、维修人员、管理员三类角色，实现报修提交、工单展示、工单状态更新、全角色页面独立权限访问等核心功能，解决传统报修无记录、无流程、无进度的问题。
 
技术架构
 
- 前端：HTML + CSS + JavaScript
- 后端：Python Flask
- 数据库：SQLite（轻量化嵌入式数据库）

实现功能
 
1. 用户登录功能
 
- 区分学生、维修员、管理员三类账号
- 不同角色登录后自动进入对应独立页面
 
2. 学生报修功能
 
- 填写报修地点、故障描述、紧急等级
- 提交生成新工单，自动存入数据库
 
3. 维修人员工单功能
 
- 查看所有待处理报修工单
- 可将「待处理工单」标记为「已完成」，实时更新状态
 
4. 管理员工单查看功能
 
- 查看系统全部报修工单
- 展示工单地点、故障、等级、状态、创建时间
 
5. 全局返回功能
 
- 学生、维修员、管理员页面均可一键返回登录页面
 
工单真实流转流程
 
学生提交报修 → 生成待处理工单 → 维修人员接单完成 → 工单状态更新为已完成

plaintext

项目亮点
 
1. 多角色权限分离：三类账号权限独立，页面隔离，符合校园管理系统设计规范。
2. 工单流程完整可用：从提交到完结的核心业务流程全部可运行。
3. 极简轻量化部署：基于 SQLite，无需配置数据库，一键启动、零环境依赖。
4. 配套设计文档齐全：附带需求说明书、ER图、业务流程图，项目开发流程规范，适合参赛评审。
